# Tech Stack

## Frontend
- **Framework:** React (Vite)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Syntax Highlighting:** Shiki
- **Icons:** Lucide React

## Backend
- **Framework:** Express.js
- **Language:** TypeScript
- **ORM:** Prisma
- **Validation:** Zod

## Database & AI
- **Database:** PostgreSQL (with pgvector for semantic search)
- **AI:** OpenAI API / LangChain
- **Environment:** Docker Compose (Local-first)
